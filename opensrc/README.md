# opensrc

This directory is an index for source code inspected through the global `opensrc` cache.

It does not contain cloned package source. Each guide card points agents to the right `opensrc path` command, why the source matters, and where to start reading.

Use these cards before inspecting package internals. Prefer official docs first, then resolve live source with `opensrc path --cwd . <package>` or the fallback repository command.
