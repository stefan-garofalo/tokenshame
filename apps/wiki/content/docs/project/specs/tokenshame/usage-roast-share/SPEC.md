# Spec: Usage Roast Share

## Context

Developers who use coding agents want a funny, shareable roast of their AI token use. A CLI reads the usage logs that those agents already write on the user's machine. It builds a small Usage Summary and opens a Share Link on the user's own Vercel app. The Share Page and Share Card render from the link alone. X shows the Share Card as the link card. ([Q1](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q1-read-local-agent-logs), [Q2](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q2-public-share-page-on-vercel), [Q32](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q32-where-the-html-is-made))

Terms follow the accepted glossary: Usage Source, Usage Summary, Share Link, Share Page, Share Card, Roast Line, Impact Estimate, Tokens Processed, Consent Prompt. See the [architecture's Canonical Terms](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/specs/tokenshame/usage-roast-share/ARCHITECTURE.md#canonical-terms).

Actors: the developer who runs the CLI, a viewer on X, and the maintainer (Stefan) who runs the Vercel app.

## Non-Goals

- No database, no stored shares, no leaderboard. ([Q6](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q6-no-storage-no-leaderboard))
- No local report page or local HTTP server. ([Q7](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q7-local-report-page-fate))
- No landing page and no methodology page on the site. The README presents the project. ([Q10](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q10-search-indexing-scope))
- No Deno no-network mode and no jq one-liner mode. ([Q14](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q14-no-network-mode-timing))
- No Cursor, Kiro, or Devin reader: their usage data is only on their servers. ([Q16](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q16-extra-agents-at-v1))
- No ozone metric. ([Q21](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q21-earth-resource-metrics))
- No login, API key, or admin key input, ever. ([Q1](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q1-read-local-agent-logs))
- No CLI-kept local history across runs (parked after v1). ([Q15](https://github.com/stefan-garofalo/tokenshame/blob/65ab515a6f2b2f1d343ef66991d7249d26368188/apps/wiki/content/docs/project/grilling/tokenshame-grill-log.md#q15-claude-older-history))
